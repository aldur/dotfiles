# Working preferences

- Use ASD-STE100 for comments and documentation.
- Keep documentation and other prose concise.
- Add comments sparingly to explain non-obvious reasons.
  Record change history in commits.
- Make references unambiguous with paths, IDs, or URLs.
- Implement only the requested scope.
- Prefer simple code that a reviewer can understand quickly.
- Reuse existing solutions. Remove duplication without adding
  unnecessary abstractions.
